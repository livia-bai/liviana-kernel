- 日期：2026-10-25

> 这篇记录是在建立修改与验错记录制度（[0006](0006-docs.md)）时事后整理的。

## 目标

把仓库的提交流程写进 AGENTS.md，让以后改代码的代理照着做。

## 改动

`AGENTS.md` 新增“提交与推送”一节：

- 仓库只有一位维护者：提交直接推到 `main`，不开分支，也不开 PR。
- 提交信息里不要带 session 链接（`Claude-Session:` 之类的行）。

## 设计决策

单人维护的仓库不需要分支和 PR 的评审流程。

## 验证

只改了文档，不涉及代码。

## 发现的问题

没有。

## 遗留问题

[0005](0005-user-mode-and-syscalls.md) 的工作会话被配置为推送到一个单独的分支，和这条规则冲突。当时先推到了那个分支，没有开 PR，向维护者确认后才推到 `main`，并按维护者的要求把提交作者改成维护者本人、保留 `Co-Authored-By: Claude`（见 [0006](0006-docs.md#发布)）。这条规则后来在 AGENTS.md 里补充了作者的要求。
